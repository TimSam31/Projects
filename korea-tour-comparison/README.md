# Korea Tour Package Comparison

Eight group-tour brochures (seven Korea, one Japan; scanned PDFs in Bahasa Indonesia) converted to Markdown and compared.

- **[korea-tour-comparison.xlsx](korea-tour-comparison.xlsx)**: styled workbook with all 8 tours: summary, price, hidden costs, days & flights, hotels, meals, terms, sightseeing (facts + opinion), assumptions

- **[comparison.md](comparison.md)**: price, number of days, hotels, meals, flights, terms, season check
- **[sightseeing-comparison.md](sightseeing-comparison.md)**: attraction matrix (facts) plus a separate subjective assessment
